## What the page exposes

The Himmotthan page embeds a public Google My Maps project titled **Himmotthan Geo-Locator**. The visible map includes district labels across Uttarakhand and Himachal Pradesh and named spring markers, including Baade nami Spring, Damtharia Spring, Mallamangra spring, Sara spring, Jagta khad (Nada spring) and Dhungro spring.

## What it does not establish

The page does not expose a visible CSV, KML, GeoJSON, shapefile, attribute-table or metadata download control. The public map therefore confirms that mapped spring/village features exist, but does not establish the complete record count, schema, measurement dates, coordinate accuracy, source method, licence or reuse permission.

## Export check

One map-export attempt using the public Google My Maps identifier was blocked by the browser client before content could be retrieved. No map data were downloaded, copied or derived from that attempt.
